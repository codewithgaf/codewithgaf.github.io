Expense Tracker & Budget Analyzer

A command-line app that answers one everyday question: where does my money go? It logs expenses, compares them with category budgets, and produces a spending report and chart.

  • Reliable by design. Each Expense validates itself, so bad data can’t enter. A corrupted data file is kept aside, not deleted.
  • Real analysis. Pandas, NumPy and Matplotlib give weekly totals, size statistics, unusually large expenses, and a budget chart.
  • Engineering habits. 19 commits, a tests folder, and a GitHub Actions workflow.
